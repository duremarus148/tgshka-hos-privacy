# TGshka HOS — privacy policy

The privacy policy of TGshka HOS, an unofficial Telegram client for HarmonyOS watches:
<https://duremarus148.github.io/tgshka-hos-privacy/> (English) ·
<https://duremarus148.github.io/tgshka-hos-privacy/ru/> (русский).

Questions and requests: [Issues](https://github.com/duremarus148/tgshka-hos-privacy/issues).
The history of the policy is the history of this repository.

Prepared policy version 3 is generated from `duremarus148/WatchGram`:
`docs/privacy-policy.json`, `docs/privacy-policy.md`, and `docs/privacy-policy.ru.md`.
Do not edit the generated HTML independently. Run `python3 tools/policy/site.py` there,
copy its `docs/public-site/` outputs here, then run
`python3 tools/policy/site.py --check --external-repo ../tgshka-hos-privacy`.
The `policy-manifest.json` records the exact HTML hashes. After a separately approved
publication, run `python3 tools/policy/site.py --check --live` from the release checkout;
a prepared branch is not evidence of a deployed policy.
